# 🔶 1. What is an If-Else Statement?

An **If-Else statement** is used to make decisions in Python.

Python checks a condition:

* If the condition is **True**, one block of code runs.
* If the condition is **False**, another block of code can run.

### Example:

```python
age = 18

if age >= 18:
    print("You are eligible.")
else:
    print("You are not eligible.")
```
