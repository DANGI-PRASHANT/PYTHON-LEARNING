# 🔶 1. What is a Set in Python?

A **Set** is a collection of unique items.

It is **unordered**, **unindexed**, and **mutable**, but the items inside it must be immutable.

You can think of a set like a real-life **mathematical set**:

* No duplicates
* No order
* Useful for checking membership
* Useful for removing duplicates

### Example:

```python
fruits = {"apple", "banana", "mango"}

print(fruits)
```

Sets are excellent when you need to store items but **order does not matter**.

# 🔶 2. How to Create a Set

### ✔ Using Curly Braces `{}`

This is the most common method for creating a set.

```python
nums = {1, 2, 3, 4}

print(nums)
```
